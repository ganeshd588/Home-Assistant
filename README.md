## 📌 Project Overview
This project demonstrates MQTT-based sensor data publishing using Python and real-time visualization inside Home Assistant.  
A custom MQTT topic is used to send:
- Temperature = 25°C  
- Humidity = 60%  
- Vibration sensor = 1  
- Student name  
- Register number  

Home Assistant reads the MQTT payload and displays all values on the dashboard.

---

## 🖥 Technologies Used
- **Home Assistant OS** (VMware Workstation 17)
- **Mosquitto MQTT Broker Add-on**
- **Python 3.13**
- **paho-mqtt library**
- **MQTT sensors in Home Assistant using YAML**
